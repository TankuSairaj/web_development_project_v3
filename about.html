About the Project

A BTech project that fights certificate forgery with instant online verification.

🎯

Objective

Let institutions issue digital certificates and let anyone verify them using a unique ID or QR code.

🧰

Technology

  • HTML5, CSS3, JavaScript
  • Node.js and Express.js
  • MongoDB with Mongoose
  • QR code generation
🔒

Security

  • bcrypt password hashing
  • JWT in HTTP-only cookies
  • Protected admin routes
  • Rate limiting and secure headers
